## 🎨 Konsep UI/UX & Filosofi Desain

Website ini dibangun dengan pendekatan **Clean Monochrome Aesthetics**, mengutamakan kesederhanaan visual yang berkelas, kontras tipografi yang tajam, serta navigasi yang intuitif. Berfokus pada performa kecepatan muat halaman (*fast loading speed*) yang instan karena berbasis web statis, tata letak responsif, serta *micro-interactions* yang cair untuk memberikan pengalaman pengguna (*user experience*) yang berkesan bagi rekruter maupun klien.

## ⚡ Fitur Utama Website (Core Features)

- **Interactive Portfolio Showcase:** Komponen interaktif berbasis Vanilla JS yang menampilkan daftar proyek unggulan lengkap dengan pop-up rincian teknologi dan tautan demo langsung.
- **Dynamic Contact Form:** Form pengiriman pesan langsung terintegrasi untuk mempermudah kolaborasi proyek secara instan.
- **Verified Credentials Section:** Ruang pameran sertifikasi profesional resmi yang dapat diverifikasi secara digital.
- **Fully Responsive & Fluid UX:** Layout adaptif menggunakan sistem utility Tailwind CSS yang beralih dengan mulus di seluruh layar perangkat, mulai dari HP, tablet, hingga monitor desktop.

---

## 🛠️ Tech Stack & Toolkit Pembuatan

Website portofolio ini dirancang murni menggunakan teknologi web dasar (*native web technologies*) demi performa yang instan dan tanpa dependensi rumit:

1. **HTML5 Semantik:** Digunakan untuk merancang struktur pondasi halaman web, layout grid portofolio, serta section informasi kontak.
2. **Vanilla JavaScript (ES6+):** Meng-handle seluruh interaktivitas web, termasuk logika pemicu modal pop-up detail proyek dan validasi input form secara dinamis tanpa bantuan framework pihak ketiga.
3. **Tailwind CSS (Via CDN/CLI):** Engine penataan visual utama berbasis utilitas untuk mempercepat pembuatan desain monokrom yang kustom, efek hover transisi yang lembut, serta pengaturan layout flexbox dan grid yang presisi.
4. **Google Fonts (Inter):** Konfigurasi tipografi sans-serif modern yang tajam untuk teks deskripsi produk dan judul agar nyaman dibaca.
5. **Vercel Hosting:** Platform *cloud deployment* untuk meng-host aset web statis secara cepat, stabil, dan aman.

## 🚀 Panduan Menjalankan Proyek Secara Lokal

Kelebihan utama dari proyek berbasis HTML & JavaScript murni ini adalah **tidak memerlukan proses kompilasi atau server lokal yang rumit**. Anda bisa langsung menjalankannya dalam hitungan detik:

### 1. Kloning Repositori
```bash
git clone https://github.com
cd portfolio
```

### 2. Cara Menjalankan Aplikasi
Anda memiliki dua cara mudah untuk membuka dan melihat aplikasi ini berjalan:

- **Cara 1 (Instan):** 
  Buka folder proyek ini melalui File Explorer komputer Anda, lalu klik dua kali pada file **`index.html`**. Web akan langsung terbuka di browser utama Anda.
  
- **Cara 2 (Menggunakan VS Code Live Server - Direkomendasikan):**
  Buka folder proyek ini di VS Code, instal ekstensi **Live Server**, kemudian klik kanan pada file `index.html` dan pilih **"Open with Live Server"**. Website akan berjalan lokal dengan fitur *Auto-Refresh* di alamat `http://127.0.0.1:5500`.
